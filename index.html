Install #

helm repo add kodus https://ilanmotiei.github.io/kodus-helm
helm repo update
helm install kodus kodus/kodus -n kodus --create-namespace -f my-values.yaml

JWT/crypto secrets auto-generate on first install and stay stable across helm upgrade — sessions don't get invalidated when you bump the chart.

What's bundled #

api · worker · webhooks · web

Four Deployments straight from the upstream Docker Compose, plus optional mcp-manager and ast services.

Postgres (pgvector) · MongoDB · RabbitMQ

StatefulSets with PVCs. Toggleable — flip .enabled: false to point at managed services.

RabbitMQ delayed-message plugin

Auto-installed via init-container. Without it, every PR review crashes with unknown exchange type 'x-delayed-message'.

wait-for-deps init containers

App pods don't CrashLoop on startup races. They nc-poll Postgres/MongoDB/RabbitMQ before booting.

Auto-generated, stable secrets

JWT, crypto, NextAuth — generated with randAlphaNum on first install, kept across upgrades via Helm's lookup.

Ingress + cert-manager

Multi-host recipes in the README. Single-host with path routing or split-host (separate webhook domain) — both work.

Helpers that hide Kodus's quirks #

Self-hosting Kodus by hand requires reading source code. Each gotcha has a chart helper:

You setChart wires
global.publicUrl.webNEXTAUTH_URL, API_FRONTEND_URL, API_USER_INVITE_BASE_URL
global.publicUrl.webhooksAPI_GITHUB_CODE_MANAGEMENT_WEBHOOK + the same for GitLab, Bitbucket, Azure Repos, Forgejo
llm.provider: anthropic + llm.apiKeyAPI_OPEN_AI_API_KEY yes really + API_ANTHROPIC_API_KEY
Kodus's source overloads API_OPEN_AI_API_KEY as the Anthropic key when the model name starts with claude-. The chart maps llm.apiKey to whichever variable Kodus actually reads.
llm.provider: openrouter | groq | cerebras | novitaAPI_OPEN_AI_API_KEY + API_OPENAI_FORCE_BASE_URL set to the right endpoint
llm.provider: geminiAPI_GOOGLE_AI_API_KEY + GEMINI_API_KEY
llm.provider: vertexAPI_VERTEX_AI_API_KEY (base64 SA JSON) + API_VERTEX_AI_LOCATION
github.app.slug: kodus-myorgWEB_GITHUB_INSTALL_URL=https://github.com/apps/kodus-myorg/installations/new
github.app.{appId,clientId,clientSecret,privateKey}API_GITHUB_APP_ID, GLOBAL_GITHUB_CLIENT_ID, API_GITHUB_CLIENT_SECRET, API_GITHUB_PRIVATE_KEY

Bring-your-own infrastructure #

Disable bundled stateful services and supply external connection details:

postgresql: { enabled: false }
mongodb:    { enabled: false }
rabbitmq:   { enabled: false }

config:
  API_PG_DB_HOST:    pg.example.com
  API_PG_DB_USERNAME: kodus
  API_PG_DB_DATABASE: kodus_db
  API_MG_DB_HOST:    mongo.example.com
  API_MG_DB_USERNAME: kodus
  API_MG_DB_DATABASE: kodus
  RABBITMQ_HOSTNAME: rabbit.example.com

secrets:
  API_PG_DB_PASSWORD: ...
  API_MG_DB_PASSWORD: ...
  API_RABBITMQ_URI:   amqp://user:pass@rabbit.example.com:5672/kodus-ai
If you point at an external RabbitMQ, install the rabbitmq_delayed_message_exchange plugin yourself. Kodus declares an x-delayed-message exchange and CrashLoops without it.

External secret managers #

Works with external-secrets, SealedSecrets, Vault, etc.:

extraExistingSecrets:
  - kodus-llm-keys
  - kodus-git-creds
extraExistingConfigMaps:
  - kodus-extra-env

Each entry is loaded into every Kodus pod via envFrom, alongside the chart-managed Secret/ConfigMap.
